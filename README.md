# To-Do-List-Application
A simple Python To-Do List application created to help increase productivity by allowing users to add, manage, and organize their daily tasks. This repository includes 4 different versions of the project developed throughout my school assessment process.

Requirements:
- tkinter preinstalled with python
- install pillow library using 
 - pip install pillow

Files needed to run the program:
- main.py
- All images files
- to_do_save_dictionary.txt (if it doesn't exist program will automatically create it)
- modules - login_page_mod.py, Images_mod.py

Instruction:
A - Login Mode
 - users enter name + password
 - after login user is asked if start fresh or load previous
 - Then user can create lists, open, delete, and etc

B - Guest Mode
 - No account created skip button clicked 
 - No data is saved and loaded
 - Save & exit just closes the program 
 - Then they can create lists/tasks, open, delete, makr complete, and etc

Note: Data only saves if user logs in and has an account in the Application
      and it they user clicks the save and exit button (yes) in the option main menu.
      (not for skipped login users save and exit button just closes program)

Your now ready to use my To-Do List Application
